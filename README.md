# Caribbean Estates

Holiday board for Port Edward, 23–26 December. Four island teams. Scores stay in the phone that writes them.

Open the site, tap Captain, enter `0000`, then pick a game from the library and save the count. Home shows the cup and the spice. Quests holds the daily word, the pose, and the photo bounties.

Export the board before you switch phones. Photos are not in this repo.
