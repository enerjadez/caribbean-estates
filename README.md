# Caribbean Estates

Holiday board for Port Edward, 23–26 December. Four island teams. Open the site and every phone sees the same cup.

https://enerjadez.github.io/caribbean-estates/

Tap Captain, enter `0000`, then pick a game and save the count. Home is the cup. Games is the library. Quests holds the daily word, the pose, and the photo bounties. Anyone can vote for what to play, and anyone can guess the word.

The captain code is the household lock on this page. The shared board itself is public to anyone with the link, so export a copy if you want a backup. Photos stay on the phone that took them. They are not in this repo and they are not on the shared board.
